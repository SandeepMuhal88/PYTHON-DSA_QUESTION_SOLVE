# Sorting Algorithms

## What is Sorting?

Sorting means arranging data in a particular order.

## Why Do We Need Sorting?

Sorting makes many operations faster.

### Example

**Without sorting:**
```
45 90 12 67 30 80
```
Finding the highest mark means checking every value.

**After sorting:**
```
12 30 45 67 80 90
```
Highest mark is immediately at the end.

### Common Use Cases

- Binary Search
- Data Analysis
- Database Queries
- Searching
- Duplicate Detection
- Ranking Systems
- E-commerce (Price Low → High)
- Game Leaderboards

> Almost every software system uses sorting.

## Types of Sorting Algorithms

There are dozens of sorting algorithms. Below are the most important ones:

| Algorithm | Difficulty | Stable | Time Complexity |
|-----------|-----------|--------|-----------------|
| Bubble Sort | ⭐ Easy | Yes | O(n²) |
| Selection Sort | ⭐ Easy | No | O(n²) |
| Insertion Sort | ⭐ Easy | Yes | O(n²) |
| Merge Sort | ⭐⭐⭐ Medium | Yes | O(n log n) |
| Quick Sort | ⭐⭐⭐ Medium | No | O(n log n) Average |
| Heap Sort | ⭐⭐⭐ Hard | No | O(n log n) |
| Counting Sort | ⭐⭐ Medium | Yes | O(n+k) |
| Radix Sort | ⭐⭐⭐ Medium | Yes | O(nk) |
